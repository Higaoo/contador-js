# ⏱️ Contador Interativo (JavaScript)

Um miniprojeto desenvolvido com o objetivo de praticar os fundamentos do desenvolvimento web front-end, integrando a estrutura do HTML, a estilização do CSS e a interatividade via JavaScript.

## 🚀 Funcionalidades
- **Incrementar (+1):** Aumenta o valor do contador a cada clique no botão correspondente.
- **Zerar (Reset):** Retorna o contador instantaneamente para o valor zero.
- **Atualização Dinâmica:** O número na tela muda em tempo real sem a necessidade de recarregar a página, utilizando manipulação do DOM.

## 🛠️ Tecnologias Utilizadas
- **HTML5:** Estruturação semântica dos elementos da página.
- **CSS3:** Estilização moderna, uso de Flexbox para centralização e efeitos visuais (`hover` e transições).
- **JavaScript (ES6+):** Lógica de programação, variáveis, captura de elementos por ID e manipulação de eventos (*Event Listeners*).
